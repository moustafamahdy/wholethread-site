Privacy Policy — Wholethread

Last updated: 25 November 2026

Summary

Wholethread does not collect, transmit, or store your data on any server of ours. Everything it does happens inside your own browser, on your own computer. There is no account, no analytics, no telemetry, and no backend.

A normal export makes no network requests. The optional Fast export (personal Teams only, teams.live.com) sends read-only requests from your browser to Microsoft Teams' own chat service, described below. Nothing is sent to us or to any third party.

What the extension accesses

When you are on teams.live.com or teams.microsoft.com and you click Export, the extension reads the conversation that is already displayed on the page — sender names, message text, timestamps, and the names of shared files — and assembles them into a file.

Three options add to that, each only when you tick it:

  • Attachments. The extension presses Teams' own Download control on each shared file and image in the conversation. Teams fetches the file from Microsoft exactly as it would if you clicked it yourself, and the extension saves it beside the export.
  • Voice message transcripts. The extension opens Teams' own View transcription for each voice message and copies the text Teams shows. Microsoft Teams produces that transcript; the extension sends no audio or text anywhere.
  • Fast export. Instead of scrolling the page, the extension asks Teams' own chat service for the messages of the chat you have open. See "Fast export and the network" below. It is off unless you tick it, and it works only on teams.live.com.

Its page code runs only on Teams pages. The downloads permission does let the browser tell it about every download that starts. Only while it waits for an attachment it clicked does it look at a download's name, address and referring page, to recognise that Teams file; any other download keeps the name the browser gave it and nothing about it is stored. A download from another Teams tab that looks the same in that moment could be filed with the export.

What it does with that data

It writes the assembled conversation to a file in your computer's Downloads folder, in the format you chose (JSON, HTML, or plain text), with any attachments in a folder next to it. Those files belong to you and stay on your machine.

A normal (scrolling) export makes no network requests, and the extension sends your conversation nowhere. The only network requests it can make are the Fast export requests described below. It requests four browser permissions, downloads, offscreen, storage and webRequest, plus access to teams.live.com, used to save files, to keep the small records described below, and to support Fast export.

Fast export and the network

Fast export is a checkbox, off by default, and works on teams.live.com only. When you tick it and press Export:

  • The extension's page script sends read-only GET requests to Microsoft Teams' own chat service, under https://teams.live.com/api/chatsvc/consumer/, for the open chat only. They go from your browser, with your own Teams session, to the same Microsoft service the Teams page already talks to.
  • To do that it needs the session header Teams sends to that service. A script on the page cannot read request headers, so the webRequest permission lets the extension's background worker see that header. It starts watching only after you tick Fast export, only in that tab, and only on requests to that address; it stops as soon as it has the header, or after two minutes. The worker hands the header only to the extension's script on the Teams page that asked for it, for the length of the export; both forget it when the export ends, and the worker also drops it when that tab is closed or loads a new page (it notes only that a page load happened, not its address). It is never written to disk, logged, exported, or sent anywhere other than back to that Teams service.
  • Nothing is sent to us or to any third party.

Attachments and voice transcripts are not collected in a Fast export.

What it stores

Two small records per conversation, in your browser's local storage for the Teams site. Both are keyed by a shortened form of the conversation's name and a hash of its full name. Fast export keys them by the conversation's internal id instead, shortened and hashed the same way, so two chats with one name stay apart.

  • Last export point: the id of the newest message from your last complete export, a number derived from its timestamp. This lets a repeat export collect only what is new instead of starting over.
  • Resume bookmark: kept only when an export was stopped or cut short, so the next one can tell you where it left off. It holds the oldest and newest points reached, the time it was saved, and a shortened form of the conversation's name (Fast export also stores the conversation's internal id).

Neither contains message text, senders, file names or links. Both stay on your computer. You can clear them at any time by clearing site data for Teams.

While attachments are downloading, the extension also keeps a note pairing each attachment with the browser's download number for it, so it can stop that download if the export is abandoned. The note holds a random identifier made for that export, the Teams id of the message, and the download number — no text, names, file names or links. It is kept in memory only, never written to disk. Each entry is removed when its download finishes, or, if the extension's background worker was paused at that moment, the next time it starts; all of them are gone when the browser closes.

One more record, in the extension's own storage, decides when to ask you for a review: how many exports have completed (it stops counting at two) and whether the request has been shown. That is all it holds, nothing about any conversation. It stays on your computer until you remove the extension, which deletes it.

A second record in the extension's own storage keeps your last date-range choice and number of days (no chat content): whether the panel was set to Everything, Last N days or Custom, and what N was. It lets the panel open the way you left it. It stays on your computer until you remove the extension, which deletes it.

What it sends to us

Nothing. There is no "us" in a technical sense — no server, no database, no collection endpoint. The authors of this extension never see your conversations, because the extension sends nothing to them. Fast export requests go to Microsoft Teams, not to us.

When you uninstall the extension, Chrome opens a page on teamsexport.com/uninstall/. The extension sends no data with that request. The page has no analytics. Like any web page, it is served by hosts (GitHub Pages, with Cloudflare in front) that receive the usual request details, such as your IP address and browser version.

Your responsibility for the exported file

The file the extension creates contains the conversation as far as it was exported, including anything the other participants wrote and the names of any files they shared, and, if you chose them, the attachments and voice transcripts that were saved. Any that could not be saved are counted in the export instead. Treat it with the same care as the conversation itself: store it somewhere appropriate, and do not share it more widely than the participants would expect.

Permissions, explained

PermissionWhy it is needed
downloadsTo save the export file. A long conversation is saved in numbered parts, and without this permission the browser blocks repeated saves from a page. It is also used to confirm the final file was saved, to remove the extension's own numbered parts afterwards, to place downloaded attachments in the export's folder, and to stop an attachment download once the browser reports it is larger than the per-file limit set in the panel (500 MB by default). That check depends on the browser knowing the size before the file finishes, so it is best effort. The per-export limit (1,000 MB by default) stops further attachments from starting; it does not cut one already downloading, so an export can pass it by up to one file. It acts only on downloads made during an export: its own files, and the attachments Teams downloads when the extension presses Download. A download from Teams that starts at the same moment as one of those can be filed with the export.
webRequestOnly for Fast export, and only after you tick it, in that tab. To see the session header Teams itself sends to its own chat service, so the extension can ask that same service for the open chat's messages. It observes only requests to https://teams.live.com/api/chatsvc/consumer/, and does not block or change any request. The header is kept in memory only and is never stored, logged, exported or sent anywhere else.
offscreenThe browser's background worker cannot turn text into a downloadable file, so the extension opens a hidden extension page that does only that, for the file being saved. It has no network access and does nothing else.
storageTo keep the extension records described under "What it stores": the download note, so a stalled attachment download can still be stopped after the browser has paused the extension's background worker (session storage, never written to disk), the review-request record (local storage: a count and whether the request was shown), and your last date-range choice and number of days (local storage, no chat content).
Access to teams.live.com and teams.microsoft.comTo read the conversation you asked to export. These are the only sites the extension is allowed to run on. Access to teams.live.com is also what allows webRequest to see the chat-service header for Fast export, and what the Fast export requests are sent to.

No other permission is requested.
